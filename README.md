## Descripción del proyecto

Este proyecto consiste en un sistema de seguimiento de hábitos (*Habit Tracker*) y gestión de tareas (*To-Do List*) desarrollado en Python.

El objetivo es ayudar al usuario a organizar sus actividades, registrar el progreso de hábitos personales y visualizar estadísticas básicas de productividad.

Actualmente el programa permite:

* Registrar hábitos.
* Registrar tareas.
* Marcar hábitos como completados.
* Marcar tareas como completadas.
* Consultar listas de hábitos y tareas.
* Calcular porcentaje de cumplimiento.
* Mostrar estadísticas de productividad.

Además, se incluyen funciones pendientes para futuras integraciones con:

* Google Calendar.
* Canvas LMS.
* Kindle.

Estas funcionalidades se encuentran declaradas y documentadas como parte de la planeación del proyecto.
